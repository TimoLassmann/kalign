# Record: the Kalign 4 protein fast setting (default mode)

Written 2026-10-15, when the setting became the default mode. This file is the single place to look up where the
protein fast setting came from, how it was chosen, and how it scored. Everything below is copied from the files it
names; nothing was re-scored for this record.

## 6. Known limitations and open points

- FAMSA is more accurate from 10,000 sequences up, and slightly on most small benchmarks (largest gaps BAliBASE RV11
  and RV30); the setting ties FAMSA at 1,000 and is faster at every size.
- Compared with the pre-release fast setting, BAliBASE RV30-50 drop (RV30 SP -0.062, TC -0.131); BaliFam100 and
  SABRE gain.
- The final fit stopped at its generation cap (100).
- The pre-release fast setting (old guide tree, build daff955) segfaulted on all four 200,000 inputs and one 50,000
  input in the lockbox; not diagnosed. The protein accurate and nucleotide presets still use the old guide tree.
- Proper timing (idle machine, 1/4/8/16 threads, wall, CPU, peak memory) is still to be done on the final binary.
